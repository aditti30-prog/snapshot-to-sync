# Snap2Calendar

Turn chat screenshots into Google Calendar events in seconds.

## What it does

Snap2Calendar reads event details from a screenshot — title, date, time, location, description — and generates a Google Calendar event link for you.

## How to use

1. Open the app.
2. Upload a screenshot (PNG, JPG, or JPEG).
3. Click **Extract Event**.
4. Review the details and open the event in Google Calendar.

No sign-in required. Your screenshots are not stored.
